# ChurchManager website prototype

This is the destination-independent prototype for the public ChurchManager
website. Open `index.html` in a browser to review the page. It uses only local
HTML and CSS and does not contact any outside service.

The approved ChurchManager identity is generated by
`tools/build_brand_assets.py`. The website keeps a local copy of the mark so it
can be deployed as a self-contained static site.

## Before publication

Replace the visibly marked placeholders for:

- the verified Windows installer, file size, and SHA-256 checksum;
- public source repository and issue tracker;
- support, security, and privacy destinations;
- public User Guide, Installation Guide, and Treasurer Guide PDFs;
- final domain and canonical URL;
- approved screenshots of the main menu, worship planner, and an accounting
  report.

Use only fictional test data in screenshots. Recommended screenshot size is
1600 by 900 pixels. Crop away unrelated windows, taskbars, notifications, chat
content, names, and local file paths before publication.

Do not connect a placeholder to an existing development installer. The public
download must come from the approved release process.

## Routine maintenance

For each release:

1. Update the version in `index.html` to match ChurchManager's authoritative
   version.
2. Update the installer link, displayed file size, and SHA-256 checksum.
3. Confirm the documentation and support links.
4. Test every link and review the page at desktop and phone widths.
5. Review public wording when a major capability changes.
6. Confirm every Upcoming Update still has an approved specification and is
   clearly distinguished from released functionality.

The full design and publication checklist is in
`Documentation/ChurchManager.Website.Specification.md`.
