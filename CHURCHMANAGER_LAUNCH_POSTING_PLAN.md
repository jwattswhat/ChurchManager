6. Send the concise release announcement to Python Announce.

## Python GUIs Showcase

### ChurchManager: open-source church administration built with wxPython

ChurchManager is a Windows desktop application designed primarily for small
congregations with limited budgets. It combines weekly administrative,
worship-planning, membership, attendance, giving, reporting, and accounting
work in one congregation-owned system.

The application is written in Python and wxPython, stores data in MariaDB, and
uses the separately licensed JSForm framework for JSON-defined screens, menus,
and reports. Its capabilities include:

- congregation, family, person, contact, and privacy records;
- worship planning with the Historic One-Year Lectionary, Orders of Service,
  propers, hymns, sermons, participants, prayers, and announcements;
- attendance, Communion, visitor, and follow-up records;
- contribution batches, donor statements, and fund designations;
- double-entry fund accounting, bank reconciliation, budgets, period controls,
  year-end work, and financial reports;
- customizable screens and reports;
- user accounts, roles, permissions, auditing, diagnostics, backup, and restore.

ChurchManager is not intended to replace Concordia Publishing House products,
hymnals, or published worship resources. It stores short references and
planning information and is meant to work alongside the resources a
congregation already uses.

The software is free and open source under GPL-3.0-or-later. There is no
required purchase or support fee. Donations are appreciated but not necessary.

## Discuss wxPython

### ChurchManager: a substantial open-source congregation application built on wxPython

I am preparing the public release of ChurchManager, a Windows desktop
application for the administrative and weekly planning needs of small
congregations with limited budgets.

ChurchManager is written in Python and wxPython, uses MariaDB, and uses the
separately licensed JSForm framework for JSON-defined screens, menus, and
reports. It includes people and family records, worship planning with the
Historic One-Year Lectionary, attendance, giving, fund accounting, scheduling,
report design, role-based permissions, auditing, and protected backup and
restore.

The project has grown into a useful real-world test of wxPython for a large,
data-centered Windows application. I would welcome feedback from the wxPython
community, particularly about installation, native Windows behavior,
accessibility, layout, and maintainable patterns for a screen-rich desktop
application.

ChurchManager is GPL-3.0-or-later and is intended to be available without a
required purchase or support fee. It complements rather than replaces CPH and
other published church resources.
